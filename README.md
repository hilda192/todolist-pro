### 🚀 ¿Qué hace?

No es una simple lista de tareas. Es un sistema completo para controlar mantenimiento de equipos, aulas, casa o trabajo.

### ✨ Funciones PRO V3

- ✅ **Preventivo vs Correctivo** - Clasificación real de mantenimiento
- 📸 **Evidencia con foto** - Toma foto con la cámara del cel
- 🔁 **Recurrencia automática** - Ej: cada 30 días se vuelve a crear
- ⚠️ **Detección de vencidas** - Te avisa cuántos días de atraso llevas
- 📊 **Dashboard** - Total, pendientes, preventivo, correctivo
- 🔍 **Buscador + Filtros inteligentes**
- 📄 **Reporte PDF** - Un clic y genera reporte para entregar
- 🌙 **Modo claro / oscuro**
- 📱 **PWA Instalable** - Funciona sin internet, se instala como app

### 🛠️ Tecnologías

- HTML5, CSS3, Vanilla JS (sin frameworks, ultra rápido)
- LocalStorage (datos siempre en tu dispositivo)
- MediaDevices API (cámara)
- Web Speech API (voz)
